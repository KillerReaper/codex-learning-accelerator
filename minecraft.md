## 🎮 GAME CONTEXT

Minecraft (Java Edition) is a survival sandbox game focused on:
- resource gathering
- crafting and progression
- exploration across multiple dimensions
- combat and survival

Players rely heavily on:
- coordinates (X, Y, Z)
- tools and materials
- biomes and structures
- dimension progression (Overworld → Nether → End)

---

## 🧠 CORE GAME KNOWLEDGE

- Diamonds spawn deep underground, best around y level -58
- Iron is required for tools like pickaxes, buckets, and armor
- Strongholds contain End Portals used to reach the End dimension
- Nether portals connect the Overworld and Nether (1 block in Nether = 8 in Overworld)
- Beds set the player's spawn point (but explode in the Nether and End)
- Coordinates are critical for navigation and locating builds or structures

---

## 🌍 DIMENSIONS

### Overworld
- Main survival world
- Contains most biomes, structures, and resources
- Day/night cycle affects mob spawning

---

### Nether
- Dangerous dimension used for progression and fast travel
- Contains:
  - Nether Fortresses (Blazes, Wither Skeletons)
  - Bastions (Piglins, loot)
- Key resources:
  - Blaze rods (for brewing and End progression)
  - Nether wart (potions)
- Lava is extremely common

---

### End
- Final progression dimension
- Contains the Ender Dragon boss
- End Cities contain:
  - Elytra (gliding wings)
  - high-tier loot
- Void damage is lethal (falling = death)

## ⛏️ RESOURCE KNOWLEDGE

- Coal → fuel and torches
- Iron → essential tools, armor, buckets
- Gold → trading with Piglins, powered rails
- Redstone → automation and mechanisms
- Lapis → enchanting
- Diamonds → high-tier tools and armor
- Emeralds → villager trading
- Netherite → strongest gear (upgraded from diamond using Netherite scraps)

---

## 🏗️ STRUCTURES

- Villages → loot, beds, trading
- Strongholds → End Portal access
- Mineshafts → rails, chests, cave spiders
- Desert Temples → loot with TNT traps
- Jungle Temples → redstone traps
- Ocean Monuments → Guardians, sponge
- Nether Fortresses → Blaze spawners, Wither Skeletons
- Bastions → Piglins, valuable loot
- End Cities → Elytra and end-game gear

---

## 🧟 MOBS

### Hostile Mobs
- Zombies, Skeletons, Creepers, Spiders
- Endermen → teleport and drop Ender Pearls
- Blazes → required for progression (Blaze rods)
- Wither Skeletons → drop skulls for Wither boss
- Piglins → trade gold for items
- Ghasts → shoot fireballs in the Nether

---

### Passive Mobs
- Cows, Pigs, Chickens → food sources
- Sheep → wool for beds
- Villagers → trading system

---

### Bosses
- Ender Dragon → required to complete the game
- Wither → optional boss, drops Nether Star

---

## ⚙️ GAMEPLAY RULES

- Tools have durability and will break
- Better materials = faster mining and stronger gear
- Correct tool tier is required (iron pickaxe for diamonds)
- Light prevents hostile mob spawning
- Hostile mobs spawn in low light levels
- Food is required to regenerate health
- Armor reduces incoming damage
